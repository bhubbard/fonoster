Fonoster Cloudflare

100% Serverless Edge Telephony

Open-Source Programmable Telecommunications running natively on Cloudflare Workers, Durable Objects, D1, R2, and Workers AI.

GET /healthz - Service Health Check
POST /v1/auth/register - Create User & Workspace
POST /v1/auth/login - User Login & JWT Token
GET/POST /v1/applications - Voice Applications
GET/POST /v1/numbers - Phone Numbers (DIDs)
GET/POST /v1/trunks - SIP Trunks
POST /v1/calls - Originate Outbound Call
WS /v1/calls/:id/media-stream - Live Audio Stream
POST /v1/ai/transcribe - Workers AI Whisper STT
POST /v1/ai/chat - Workers AI Autopilot Agent
GET /v1/cdrs - Call Detail Records
